# NyxR Companion

Plays audio CDs from an optical drive, Bluetooth audio from phones and AirPlay from iPhones on an AirPlay 2 speaker, such as a HomePod, through [nyxr](https://github.com/pStrikeZ/Nyx-Refrain). Controlled from Home Assistant with the NyxR Companion integration.

See the Documentation tab, or the [project page](https://github.com/pStrikeZ/Nyx-Refrain-Companion).
